# Roadmap

Planned directions for SantaClara Aegis. Priorities are shaped by subscriber
feedback and regulatory evolution.

## Near term

- **Self-service scenario authoring** — a guided UI to define custom events
  against a client ODD, with automatic regulatory-reference tagging.
- **More corridors** — packaged OpenDRIVE extracts for additional U.S. and
  EU urban corridors.
- **Expanded catalog** — additional weather (fog, glare), sensor-failure, and
  V2X-enabled scenarios.

## Mid term

- **Perception-in-the-loop** — inject camera/LiDAR sim outputs to validate
  downstream stacks, not just ego kinematics.
- **Regression benchmarking** — track a client's algorithm version-over-version
  on a fixed scenario set, with trend reports.
- **SOTIF / ISO 21448 alignment** — explicit unknown-unsafe scenario coverage
  reporting.

## Long term

- **On-prem / private-cloud deployment** — run the full engine inside a
  client's environment for maximum data control.
- **Closed-loop training packs** — curated scenario bundles for ADAS/AD
  perception and planner training.
