# 收款码放置说明（自动收款的关键一步）

把下面这个文件放在这个目录，销售页的「立即购买」弹窗就会显示你的真实收款码，客户扫码即付款、你即刻收到钱：

| 文件 | 用途 | 怎么拿到 |
|------|------|----------|
| `wechat.png` | 微信收款码 | 微信 → 我 → 服务 → 收付款 → 二维码收款 → 保存二维码图片，命名为 `wechat.png` |

## 没有这两个文件时会怎样？
弹窗会自动变成「放入收款码」占位提示，并引导客户到留资表单留邮箱——**不会漏掉任何客户**，只是需要你手动跟进收款。

## 海外信用卡（自动收款，可选）
打开 `index.html` 顶部 `<script>` 里的 `PAY` 配置，把 `stripe` / `lemon` 填成你的付款链接
（Stripe Payment Link 形如 `https://buy.stripe.com/xxxx`）。填了之后，订阅按钮会直接跳转到信用卡付款页，钱自动进账。

## 改完之后
把 wechat.png 提交并推送（见仓库 PLAYBOOK / docs/deploy-and-promote.md），GitHub Pages 会自动更新。
